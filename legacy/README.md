# CRA migration snapshot

Retained source, package manifests, public HTML template and original metadata-prerender script from the pre-migration implementation. This directory is comparison evidence, not a second maintained/runnable application. It contains no environment file or credentials. The original built site and browser baseline remain ignored under `output/migration-baseline/`.

Current implementation, commands and authority live at the repository root. Remove this snapshot only when it is no longer useful for migration acceptance; Git history also retains the original source.
