## Decisions

- IntersectionObserver with `rootMargin: '-50% 0px -50% 0px'` over tall sentinel bands, recomputing stage from live geometry on every entry (self-healing; no missed-crossing state drift). Chosen over observing the track itself, whose intersectionRatio plateaus while the panel is pinned, and over a scroll listener, staying with the spec's named mechanism.
- Same markup in both modes; the reduced-motion collapse is pure CSS (`@media (prefers-reduced-motion: reduce)`), with the observer effect early-returning when reduced motion is requested or IO/matchMedia are unavailable (also keeps jsdom safe).
- Panel lines are paragraphs, not headings, so the h1 → h2 document outline stays clean.
- Panel uses `100dvh` with `100vh` fallback for mobile toolbar behaviour.
